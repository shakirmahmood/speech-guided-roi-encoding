# Glossary

Terms agreed with the project owner. Use only these terms or plain words in code comments, docs, notes and
replies. Before using any other term (a field name, metric, label, abbreviation, or technical or coined
phrase), ask the owner what to call it, then add it here with the date it was agreed. Prefer established
research terminology where one exists.

| Term | Meaning | Agreed |
|---|---|---|
| **object** | A physical thing in the video: a person, animal, tool, food item, and so on. Use instead of "thing" or "entity". | 2026-10-19 |
| **referent** | The object that a word or phrase in the speech points to ("it" → the zucchini). Use only when talking about what the speech points to. | 2026-10-19 |
